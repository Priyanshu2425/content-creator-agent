# [whoosh.md](http://whoosh.md)

name: whoosh  
duration_seconds: 0.57  
category: transition  
intensity: medium  
frequency_budget: medium

## Description

A fast movement transition.

Feels like visual motion, direction, and energy.

The purpose is to connect two visually different shots and make the transition feel intentional.

## Best Uses

- Talking head → B-roll
- B-roll → talking head
- Screen recording reveals
- Zoom transitions
- Asset changes
- Screenshot sequences
- Scene transitions

## Avoid Using For

- Every sentence cut
- Every jump cut
- Dense educational pacing
- Rapid-fire edits

Overuse causes the edit to feel noisy and amateur.

## Editing Intent

Use when visual context changes significantly.

The sound should imply motion between scenes.

## Example Timeline

Speaker explaining concept

WHOOSH

## Usage Frequency

Recommended usage:  
15-25% of cuts.

## AI Decision Rule

IF:

- scene changes
- visual context changes
- entering or leaving B-roll
- entering or leaving screen recordings

use whoosh
